Alur Kerja & Perbandingan Teknis

Mengapa Absenta.id jauh lebih unggul, hemat, dan disukai guru/kurikulum dibanding CBT Konvensional (LMS Biasa).

🌐 Arsitektur CBT Konvensional (LMS)

Sistem sentralisasi database tunggal yang rawan crash saat jam sibuk ujian serentak karena semua data tertumpuk di server pusat.

🛡️ Absenta.id - Orkestrator Ujian

Sistem terdesentralisasi: portal memuat roster & jadwal dari Database Sekolah (Supabase Cloud), sedangkan pengisian soal langsung ditangani server Google (anti-down).

Parameter Fitur 🌐 CBT Konvensional (LMS Lain) 🛡️ Absenta.id - Orkestrator Ujian
Alur Pembuatan Soal & Nilai Sentralisasi Kaku (Beban Kurikulum):
Guru menyetor file Word/Excel → Kurikulum input manual satu per satu ke LMS → Hasil nilai disetor kembali dari Admin ke Guru. 		Desentralisasi Mandiri (Hemat Waktu 95%):
Guru membuat soal langsung di Google Forms. Portal Ujian memuat roster siswa dari Database Sekolah (Supabase Cloud), dan jawaban masuk langsung ke Google Drive Guru secara instan.
Risiko Server Down / Lag Sangat Tinggi (Jam Puncak):
Menggunakan shared cloud server. Ratusan ribu siswa klik "Kirim" bersamaan rawan membuat server lag atau crash (Error 503). 		Hampir 0% (Infrastruktur Google):
Server lisensi & database sekolah hanya memproses query ringan (data login & jadwal). Pengiriman jawaban sepenuhnya ditangani oleh kapasitas Google.
Kurva Belajar Guru Tinggi & Rumit:
Guru wajib mempelajari editor bank soal sistem baru. Rumus matematika, simbol fisika, atau tabel sering rusak saat dipindahkan. 		Sangat Rendah (Tanpa Belajar):
Guru tetap 100% menggunakan Google Forms yang sudah biasa mereka pakai. Cukup salin tautan soal dalam 5 detik.
Kepemilikan Data Jawaban Pihak Ketiga:
Data nilai dan soal disimpan di server database pihak ketiga, bukan di bawah kontrol langsung sekolah. 		Milik Sekolah (Kedaulatan Data):
Soal dan database nilai tersimpan aman di akun Google Drive / Spreadsheet milik guru atau instansi sekolah masing-masing.
Batasan Jumlah Siswa Dibatasi Ketat:
Jumlah siswa dibatasi sesuai paket (Maksimal 1.000 atau 1.500 siswa). Sekolah harus membayar lebih mahal jika jumlah siswa bertambah. 		Tanpa Batas (Unlimited):
Bebas daftarkan siswa dan perangkat sebanyak apa pun tanpa biaya tambahan per kepala.

☁️ Cloud SaaS

Langsung Pakai,
Tanpa Ribet

☁️

Tidak perlu server, tidak perlu tim IT. Cukup daftar, bayar, dan sistem langsung siap digunakan oleh seluruh sekolah Anda melalui browser manapun.

  • ✦ Tidak perlu instalasi — langsung aktif dalam hitungan menit
  • ✦ Akses via browser dari perangkat apapun
  • ✦ Update fitur otomatis tanpa tindakan IT
  • ✦ Subdomain sekolah pribadi (contoh: smk.absenta.id)
  • ✦ Infrastruktur dikelola penuh oleh tim Absenta
  • ✦ Cocok untuk semua sekolah tanpa staff IT

🖥️

Untuk sekolah atau lembaga yang ingin menginstal sistem di server mereka sendiri. Data sensitif siswa tidak pernah meninggalkan jaringan internal Anda.

  • ✦ Data 100% tersimpan di server sekolah sendiri
  • ✦ Berjalan tanpa koneksi internet (intranet lokal)
  • ✦ Kustomisasi bebas sesuai kebijakan IT sekolah
  • ✦ Cocok untuk pesantren, madrasah, sekolah BUMN/TNI
  • ✦ Kontrol penuh atas update dan konfigurasi sistem
  • ✦ Lisensi hardware-locked per server
