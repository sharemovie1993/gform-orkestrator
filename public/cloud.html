Mengapa Pilih Cloud SaaS?

Semua manfaat sistem ujian CBT profesional, tanpa kerumitan teknis

🚀

Aktif dalam 5 Menit

Selesaikan pembayaran dan sistem langsung aktif otomatis. Tidak perlu menunggu setup atau konfigurasi dari tim teknis.

🖥️

Zero Infrastructure

Tidak perlu membeli server, UPS, atau switch tambahan. Semua infrastruktur dikelola dan dipantau 24/7 oleh tim Absenta.

🔒

Subdomain Pribadi Sekolah

Setiap sekolah mendapat subdomain eksklusif seperti smkn1anda.absenta.id — URL yang bisa dibagikan langsung ke siswa.

🔄

Update Fitur Otomatis

Setiap fitur baru, perbaikan bug, dan peningkatan performa langsung tersedia tanpa tindakan apapun dari pihak sekolah.

🛡️

Keamanan Enterprise

HTTPS otomatis, enkripsi data saat transit dan di-rest, serta proteksi DDoS sudah aktif secara bawaan untuk semua pelanggan.

📱

Perangkat Tak Terbatas

Tidak ada batasan jumlah smartphone siswa yang bisa terhubung dalam satu lisensi sekolah — bayar per sekolah, bukan per perangkat.

📊

Dashboard Real-Time

Panel proktor yang bisa diakses dari perangkat manapun. Pantau sesi ujian, status koneksi siswa, dan log aktivitas secara langsung.

💬

Dukungan Teknis Inklusif

Semua paket sudah termasuk akses dukungan via email dan WhatsApp. Tidak ada biaya tambahan untuk support teknis.

💳

Pembayaran Fleksibel

Bayar via QRIS, Virtual Account bank manapun, atau kasir ritel (Alfamart/Indomaret). Lisensi aktif otomatis dalam 5 detik setelah pembayaran.

💡
Cloud vs On-Premise — Mana yang Tepat untuk Anda?

Jika sekolah Anda memiliki tim IT dan kebijakan data ketat (data harus di server sendiri), pertimbangkan layanan On-Premise. Jika tidak, Cloud SaaS adalah pilihan terbaik — lebih murah, lebih mudah, dan lebih cepat aktif.

Lapisan Infrastruktur Cloud Absenta
CDN
Cloudflare CDN — Distribusi Global & Proteksi DDoS

Semua request melewati Cloudflare untuk mempercepat loading, memproteksi dari serangan, dan memastikan ketersediaan layanan tinggi (99.9% SLA).

SSL/TLS
HTTPS Otomatis — Enkripsi End-to-End Bawaan

Sertifikat SSL dikelola otomatis. Semua komunikasi antara perangkat siswa dan server terenkripsi dengan TLS 1.3 — tanpa konfigurasi dari sekolah.

API
Absenta API Server — Multi-Tenant Architecture

Setiap sekolah berjalan dalam lingkungan yang terisolasi (tenant). Data sekolah A tidak bisa diakses oleh sekolah B, meskipun berbagi infrastruktur fisik.

DB
PostgreSQL Cluster — Database Redundant

Database dengan replikasi otomatis (primary + replica). Jika satu node bermasalah, sistem failover ke replica dalam hitungan detik tanpa kehilangan data.

Backup
Automated Backup — Snapshot Harian & Point-in-Time Recovery

Backup otomatis setiap 6 jam ke object storage geo-redundant. Data sekolah dapat dipulihkan ke kondisi manapun dalam 30 hari terakhir.

Langkah Mulai Pakai

Dari nol hingga ujian pertama berjalan — panduan lengkap untuk operator sekolah

1

Ajukan Lisensi & Pilih Paket

Buka halaman Harga Paket di absenta.id, pilih paket yang sesuai jumlah siswa, lalu klik "Ajukan Lisensi". Isi formulir data sekolah — nama sekolah, nama proktor utama, dan subdomain yang diinginkan.

💡 Pilih subdomain yang mudah diingat siswa, misalnya: smkn1kota → akan menjadi smkn1kota.absenta.id. Subdomain tidak bisa diubah setelah aktif, jadi pilih dengan cermat.
2

Selesaikan Pembayaran

Pilih metode pembayaran yang paling nyaman: QRIS, Virtual Account (BCA, Mandiri, BNI, BRI, dll), atau kasir ritel (Alfamart/Indomaret). Sistem Tripay kami akan memproses pembayaran secara otomatis.

absenta.id/checkout/INV-XXXXXX
// Status pembayaran (real-time polling) status : "PAID" ✓ metode : "QRIS" nominal : "Rp 299.000" waktu_bayar : "2025-06-01 09:14:33" lisensi : "⚡ Aktif otomatis dalam 5 detik"
⚠️ Simpan nomor invoice dan email konfirmasi. Kunci lisensi dan kredensial admin akan dikirim ke email yang didaftarkan setelah pembayaran terverifikasi.
3

Akses Panel Admin Sekolah

Setelah lisensi aktif, buka subdomain sekolah Anda dan login ke panel admin dengan kredensial yang diterima via email. Panel admin adalah pusat kendali semua ujian sekolah Anda.

smkn1kota.absenta.id/admin
// Dashboard Panel Proktor sekolah : "SMKN 1 Kota Anda" lisensi : "AKTIF ✓ — Berlaku hingga 2026-06-01" sesi_aktif : 0 total_ujian : 0 subdomain : smkn1kota.absenta.id
4

Buat Soal di Google Forms

Absenta bekerja dengan soal ujian dari Google Forms biasa yang sudah Anda buat. Tidak perlu membuat ulang soal atau migrasi ke format khusus.

forms.google.com → Salin Link Soal
// Salin URL Google Forms soal Anda URL soal : https://forms.gle/xxxxxxxxxxxxx // Pastikan "Kumpulkan alamat email" = NONAKTIF // Respons dibatasi 1x per orang = OPSIONAL
💡 Anda bisa menggunakan soal pilihan ganda, isian singkat, paragraf, dan unggah file. Semua jenis soal Google Forms didukung penuh oleh Absenta.
5

Buat Sesi Ujian di Panel Admin

Di panel admin, buat sesi ujian baru: masukkan nama ujian, mata pelajaran, URL soal Google Forms, batas waktu, dan jadwal mulai/selesai. Panel akan menghasilkan kode sesi untuk siswa.

smkn1kota.absenta.id/admin → Buat Sesi
nama_ujian : "UAS Matematika Kelas XII IPA" mapel : "Matematika" url_soal : https://forms.gle/xxxxx durasi : 90 menit mulai : "2025-06-10 08:00" kode_sesi : "ABST-7742" ← bagikan ke siswa
6

Siswa Install Absenta App & Mulai Ujian

Siswa mengunduh aplikasi Absenta dari Google Play Store, masukkan kode sesi dari proktor, dan aplikasi akan mengunci perangkat ke mode ujian penuh — mencegah akses ke aplikasi lain, notifikasi, dan screenshot.

✅ Yang Dikunci Kios Mode
  • 🔒 Keluar dari aplikasi ujian
  • 🔒 Buka aplikasi lain (WA, browser, dll)
  • 🔒 Screenshot dan screen record
  • 🔒 Split screen dan multitasking
  • 🔒 Notifikasi dari aplikasi lain
👁️ Yang Dipantau Proktor
  • 📊 Status koneksi tiap perangkat
  • ⏱️ Waktu tersisa per siswa
  • 🚨 Peringatan keluar layar (jika ada)
  • 📝 Log aktivitas sesi
  • ✅ Konfirmasi submit jawaban
7

Lihat Hasil di Google Forms

Setelah ujian selesai, semua jawaban sudah tersimpan otomatis di Google Forms Anda. Buka Google Forms → Respons → lihat spreadsheet hasil ujian, atau ekspor ke Google Sheets untuk penilaian.

💡 Gunakan fitur "Nilai" di Google Forms untuk membuat kunci jawaban dan penilaian otomatis jika menggunakan soal pilihan ganda. Absenta tidak mengubah data respons — semua tersimpan langsung di akun Google Anda.
